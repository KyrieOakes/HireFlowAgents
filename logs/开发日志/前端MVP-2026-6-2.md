# 前端 MVP 实现 — 2026-06-02

## 本次改动概述

实现 HireFlow 前端 MVP：Next.js + TypeScript + Tailwind CSS，覆盖 Phase 1.1 后端所有能力。

## 详细改动

### 项目配置 (6 个文件)
| 文件 | 内容 |
|---|---|
| `package.json` | Next.js 14 + React 18 + TailwindCSS 3 + TypeScript 5 |
| `tsconfig.json` | strict mode + path alias `@/*` |
| `next.config.js` | Pages Router |
| `tailwind.config.js` | 扫描 pages/ + components/ |
| `postcss.config.js` | Tailwind + Autoprefixer |
| `styles/globals.css` | 全局样式: 灰底白卡 HR/ATS 风格 |

### API 服务层 (1 个文件)
| 文件 | 说明 |
|---|---|
| `services/api.ts` | 11 个 API 函数: `listJobs/uploadJob/parseJob/getJob/listCandidates/uploadResume/parseResume/getCandidate/runMatching/getRanking/getMatchDetail` |

### 通用组件 (7 个文件)
| 组件 | 功能 |
|---|---|
| `Layout.tsx` | 顶部导航 (首页/岗位/简历/匹配) + 当前页高亮 |
| `StatusBadge.tsx` | Strong Match=绿色, Medium=蓝色, Weak=黄色, NR=红色 |
| `ScoreBar.tsx` | 分数进度条, ≥80绿/≥65蓝/≥50黄/<50红 |
| `EmptyState.tsx` | 空状态: 图标+标题+描述+操作按钮 |
| `ErrorMessage.tsx` | 错误横幅: 消息+后端未启动提示+重试按钮 |
| `LoadingButton.tsx` | 带旋转动画的按钮, 支持 primary/secondary/danger |
| `JsonPanel.tsx` | 可折叠 JSON 面板, 递归格式化 |

### 页面 (4 个文件)
| 页面 | 功能 |
|---|---|
| `pages/index.tsx` | Dashboard: 岗位/候选人统计卡片 + 快捷操作 + 流程提示 |
| `pages/jobs.tsx` | 岗位管理: 新建(文本粘贴)→解析→列表→详情弹层(Rubric+Profile) |
| `pages/resumes.tsx` | 简历管理: 录入(粘贴/文件读取)→解析→列表→详情弹层(CandidateProfile) |
| `pages/matching.tsx` | 匹配排名: 选岗位→匹配→排名表(分数条+优势+风险)→详细评分弹层(维度+证据) |

### TypeScript 类型 (1 个文件)
| 文件 | 说明 |
|---|---|
| `types/index.ts` | Job/Candidate/JDProfile/CandidateProfile/MatchResult/RankingResult 等全部接口 |

## 运行方式

```bash
# 终端 1: 后端
conda activate hireflowagents
docker compose up -d postgres qdrant
uvicorn app.main:app --reload

# 终端 2: 前端
cd frontend && npm run dev
# → http://localhost:3000
```
