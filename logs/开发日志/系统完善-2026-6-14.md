# 系统完善 — 2026-06-14

## 本次改动概述

修复 5 个 Bug + 新增两阶段排序 + 强制中文输出 + 文档更新。

## 系统流程图

```
前端 (Next.js localhost:3000)
    │
    ├─ Dashboard → 岗位/候选人统计
    ├─ 岗位管理 → CRUD + 解析 + 删除
    ├─ 简历管理 → PDF上传 → 自动解析 → 自动命名
    └─ 匹配排名 → 选岗位 + limit → 粗筛 → 精排 → 排名

后端匹配流程 (两阶段):
  全部候选人 → pre_screening.py (关键词粗筛, <1ms/人)
    → Top N×3 候选人 → Match Agent (LLM 精排)
    → Ranking Agent (排序) → 展示 Top N

Prompt 体系 (全部强制中文):
  JD Agent → [语言要求] → 中文 JD Profile
  Resume Agent → [语言要求] → 中文 CandidateProfile
  Match Agent → [语言要求] + 后处理翻译 → 中文评分
```

## 详细改动

### Bug 修复 (5项)
| Bug | 修复 |
|---|---|
| 解析后名字被覆盖 | crud.py: 原名以"申请人"开头时保护 |
| 匹配无进度 | 蓝色进度卡片 + 每秒计时器 |
| 排名显示 ID 乱码 | 姓名映射表 nameMap[cid] |
| Top5 显示 10 个 | GET /ranking?limit=N |
| crud.py 语法错误 | 删除多余 `)` |

### 新功能 (4项)
| 功能 | 实现 |
|---|---|
| 文件上传 | POST /resumes/upload-file + PyMuPDF/python-docx |
| 匿名命名 | 申请人A/B/C... → 26进制字母循环 |
| 两阶段排序 | pre_screening.py + Match Agent |
| 强制中文 | 3个Agent prompt [语言要求] + match_agent 后处理批量翻译 |

### 删除功能
- DELETE /jobs/{id} + 前端红色按钮 + confirm
- DELETE /resumes/{id} + 前端红色按钮 + confirm

### 匹配人数限制
- POST /jobs/{id}/match?limit=5/10/15
- GET /jobs/{id}/ranking?limit=N

### Prompt 优化
- 所有 Agent: [语言要求] 提到 prompt 第一行
- Match Agent: 增加后处理翻译 (检测英文→批量翻译)

## 当前系统指标
