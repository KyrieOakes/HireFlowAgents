### 分层说明

```
Layer 1: Agent 单元测试 (24 tests)
  ├─ 每个 Agent 测试 3-5 个场景
  ├─ 全部 mock call_llm / call_llm_structured
  ├─ 覆盖: 正常输出 / JSON回退 / 批量调用 / 提示词构造
  └─ 零外部依赖, 纯 Python

Layer 2: CRUD 集成测试 (9 tests)
  ├─ SQLite :memory: 内存数据库
  ├─ 表自动创建 (Base.metadata.create_all)
  ├─ 覆盖: 创建/查询/更新/删除/级联/邮件审批
  └─ 每个测试独立, 事务回滚

Layer 3: API 集成测试 (10 tests)
  ├─ FastAPI TestClient + SQLite 文件临时库
  ├─ dependency_overrides 替换 get_db
  ├─ 覆盖: 岗位/简历/面试/邮件/审批 路由
  └─ 测试路由存在性, 非业务逻辑正确性

Layer 4: 端到端冒烟测试 (1 test)
  ├─ 完整7步链路: JD→简历→匹配→面试→评价→邮件
  ├─ Mock 全部 LLM 调用
  ├─ 验证: 路由正常 / 数据流转 / 字段存在
  └─ 打印 job_id + candidate_id 方便调试
```

## 技术要点

**mock LLM 方式:**
```python
with patch("app.agents.xxx.call_llm") as mock:
    mock.return_value = '预设的JSON字符串'
    result = await agent_function(...)
```

**SQLite 测试隔离:**
- CRUD 测试: `:memory:` + 事务回滚 (每测试独立)
- API 测试: 文件临时库 (跨线程兼容) + 模块级 fixture

**FastAPI 依赖注入替换:**
```python
app.dependency_overrides[get_db] = override_get_db
```
