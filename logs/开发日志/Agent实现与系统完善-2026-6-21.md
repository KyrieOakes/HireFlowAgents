## 详细改动

### 一、三个 Agent 实现

#### 1. Interview Agent (`app/agents/interview_agent.py`)
| 功能 | 说明 |
|---|---|
| `generate_questions()` | 生成 6-10 个定制化面试问题 |
| 问题类型 | technical (技术)/ project_deep_dive (项目深挖)/ behavioral (行为)/ risk_verification (风险验证) |
| 输入依赖 | JD profile + Candidate profile + Match result (risks) |
| 中文输出 | prompt 头部 `【语言要求 - 最高优先级】` |
| 回退机制 | LLM 返回无效 JSON 时自动生成默认问题 |

**生成规则:**
- 技术问题: 来自 JD 的 required_skills + technical_requirements
- 项目深挖: 来自候选人 projects 中的具体项目
- 行为问题: 来自 JD 的 soft_skills
- 风险验证: 来自 match_result 的 risks 列表

#### 2. Evaluation Agent (`app/agents/evaluation_agent.py`)
| 功能 | 说明 |
|---|---|
| `evaluate_candidate()` | 基于面试反馈生成结构化评价 |
| 评价维度 | technical_depth_score (1-10) / communication_score (1-10) / problem_solving_score (1-10) |
| 风险解决 | risk_resolution: 对 match 阶段风险点逐一评估 (resolved/partially_resolved/unresolved) |
| recommendation | "Strongly Recommend" / "Recommend" / "Hold" / "Not Recommend" |
| 安全锁 | `requires_human_review` 固定为 True, recommendation 只是建议 |

**关键约束:**
- 必须基于 interview_feedback，不允许只根据简历下结论
- 反馈不足时在 concerns 中明确标注
- 不输出最终录用/不录用决策

#### 3. Email Agent (`app/agents/email_agent.py`)
| 功能 | 说明 |
|---|---|
| `generate_email_draft()` | 生成 HR 邮件草稿 |
| 邮件类型 | interview_invite (面试邀请) / rejection (拒信) / follow_up (跟进) / next_round (下一轮) |
| 安全锁 | `status="draft"` + `requires_human_approval=True` |
| 约束 | 不编造时间/地点/薪资/录用承诺 |

**各类型特点:**
- interview_invite: 正式友好, 时间地点写"待HR确认后另行通知"
- rejection: 礼貌、克制、温暖, 不输出评分/伤害性评价
- next_round: 肯定表现, 预告下一轮
- follow_up: 询问反馈, 告知后续流程

### 二、API 闭环 (7 个新端点)

| 端点 | 方法 | 功能 |
|---|---|---|
| `/jobs/{id}/candidates/{id}/questions` | POST | 调用 Interview Agent 生成问题, 保存 DB |
| `/jobs/{id}/candidates/{id}/questions` | GET | 获取已生成的问题列表 |
| `/jobs/{id}/candidates/{id}/evaluate` | POST | 提交面试反馈, 调用 Evaluation Agent |
| `/jobs/{id}/candidates/{id}/evaluation` | GET | 获取结构化评价 |
| `/jobs/{id}/candidates/{id}/email-draft` | POST | 调用 Email Agent 生成草稿 |
| `/jobs/{id}/candidates/{id}/email-draft` | GET | 获取草稿列表 |
| `/email-drafts/{id}/approve` | POST | 人工审核批准 (只改状态, 不发送) |

## 安全与合规

| 规则 | 实现 |
|---|---|
| Agent 不能做最终决定 | requires_human_review = true |
| 邮件只生成草稿 | status = "draft" |
| 邮件发送需审批 | POST /email-drafts/{id}/approve 只改状态 |
| 不编造时间地点 | "待HR确认后另行通知" |
| 拒信不输出伤害性评价 | prompt 明确要求礼貌克制 |
| API Key 不硬编码 | 从 .env 读取, config.py 默认为空字符串 |
