### 1. 评估 Notebook (`evaluation/系统评估报告.ipynb`)

创建了一个完整的 Jupyter Notebook，运行后可输出系统评估报告。

**包含 10 个 Cell:**

| Cell | 功能 |
|---|---|
| Cell 1 | 报告元信息 (日期 + 具体时间, 如 "2:30 PM") |
| Cell 2 | 系统架构图 (ASCII 可视化) |
| Cell 3 | 配置检查 (LLM模式/数据库/Embedding/Chunk参数) |
| Cell 4 | LLM 连接测试 (本地 LM Studio + Embedding) |
| Cell 5 | 数据库连接测试 (PostgreSQL + Qdrant) |
| Cell 6 | 单步骤测试 (JD解析 / Resume解析, 含耗时) |
| Cell 7 | 完整 Pipeline 测试 (4步骤, 含时间线) |
| Cell 8 | 性能与质量报告 (时间分布/分数分布/问题检测/统计) |
| Cell 9 | 候选人详细评分 (维度分数可视化条形图) |
| Cell 10 | 项目文件结构统计 (Python文件数 + 代码行数) |

**时间格式:** 使用悉尼时区，格式如 `2:30 PM`、`10:15 AM`
