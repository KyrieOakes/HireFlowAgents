# 评估体系升级 — 2026-05-31

## 本次改动概述

将评估从"手动看"升级为"自动化指标 + 历史对比"。新增 run_eval.py 脚本和 Notebook 对比功能。

## 系统流程图

```
Notebook Cell 1-3                Cell 4                         Cell 5
    │                              │                              │
    ├─ 初始化(时间戳/路径)          ├─ 计算评估指标               ├─ 扫描 reports/*.json
    ├─ 健康检查                   │  Precision@1/2/3            │  取最近5个
    └─ Pipeline运行              │  NDCG@3                     ├─ 对比表格:
         │                       │  Spearman ρ                 │  耗时变化(更快/更慢)
    JD解析 → 简历解析              │  score range                │  指标趋势(↗↘→)
      → 匹配评分 → 排序            ├─ 写入 reports/xxx.json      │  排名一致性
                                  └─ 写入 reports/xxx.md        └─ 变化总结

run_eval.py (独立脚本)
    │
    ├─ 同一套测试数据
    ├─ 同一套指标计算
    ├─ 输出 .md + .json
    └─ 用法: python evaluation/run_eval.py
```

## 详细改动

### run_eval.py
| 功能 | 说明 |
|---|---|
| `_build_proxy_relevance()` | JD 关键词在简历中的命中率 → 代理 Ground Truth |
| `precision_at_k()` | Top K 中真正相关的比例 |
| `ndcg_at_k()` | 归一化折扣累积增益 (排序质量) |
| `spearman_rank_correlation()` | 秩相关系数 (排序一致性) |
| `run_evaluation()` | 完整 Pipeline + 指标计算 |
| `save_results()` | 输出 .md + .json 双格式 |

### Notebook 升级
| Cell | 改动 |
|---|---|
| Cell 4 | 新增指标计算 (P@K/NDCG/Spearman) + JSON 输出 |
| Cell 5 | 新增历史对比: 扫描 reports/ 中 JSON 文件, 展示趋势表 |

### 对比功能
- 扫描 `reports/*.json` → 取最近 5 次
- 3张对比表: 耗时 / 指标 / 排名一致性
- 自动计算变化趋势
- < 2 次记录时友好提示

## 评估指标说明

| 指标 | 含义 | 当前值 |
|---|---|---|
| Precision@1 | Top 1 是否真正合适 | 1.000 |
| Precision@3 | Top 3 中合适的比例 | 1.000 |
| NDCG@3 | 排序与理想排序的接近度 | 1.000 |
| Spearman ρ | 排序相关性 | 1.000 |

注意: 当前使用 JD 关键词命中率作为代理 Ground Truth。
E001 和 E003 都命中全部 5 个关键词 (1.0)，E002 命中 3/5 (0.6)，
所以当系统将 E001/E003 排在前面时，指标均为满分。
真正准确的评估需要人工标注替换。
