# 功能完善 v2 — 2026-06-14

## 本次改动概述

修复 3 个 Bug + 新增删除功能 + 匹配人数限制。

## 系统流程图

```
前端 pages/                          后端 API
    │                                    │
    ├─ index.tsx (Dashboard)             │
    │   └─ 已解析统计(has_profile)        │
    │                                    │
    ├─ jobs.tsx (岗位管理)               ├─ DELETE /jobs/{id}
    │   └─ 创建/解析/删除                 ├─ POST /jobs/{id}/parse
    │                                    ├─ GET /jobs/
    │                                    │
    ├─ resumes.tsx (简历管理)            ├─ POST /resumes/upload-file (PDF)
    │   └─ 上传/解析/删除                 ├─ POST /resumes/{id}/parse
    │   └─ 上传→自动解析→滚动到卡片       ├─ DELETE /resumes/{id}
    │                                    ├─ GET /resumes/
    │                                    │
    └─ matching.tsx (匹配排名)           ├─ POST /jobs/{id}/match?limit=N
        └─ 选择岗位+limit→匹配            │   └─ 支持 Top5/10/15/全部
        └─ 进度卡片(已等待Xs)             ├─ GET /jobs/{id}/ranking
        └─ 姓名映射(nameMap)              └─ GET /jobs/{id}/candidates/{id}/detail
        └─ 详细评分弹层
```

## 详细改动

### Bug 修复
| Bug | 修复 |
|---|---|
| 解析后名字被覆盖 | `crud.py`: 原名以"申请人"开头时不被 LLM 覆盖 |
| 匹配无进度提示 | 蓝色进度卡片 + 每秒计时器: "正在匹配中... 已等待 15s" |
| 排名显示ID乱码 | 加载 candidates 列表 → `{id→name}` 映射 → 显示姓名 |

### 新功能
| 功能 | 后端 | 前端 |
|---|---|---|
| 匹配人数限制 | `POST /jobs/{id}/match?limit=N` | 下拉选 Top5/Top10/Top15/全部 |
| 删除岗位 | `DELETE /jobs/{id}` | 红色删除按钮 + confirm 确认 |
| 删除候选人 | `DELETE /resumes/{id}` | 红色删除按钮 + confirm 确认 |

### Agent Prompt 统一中文输出
- jd_agent.py: JD 分析结果用中文
- resume_agent.py: 技能/学位/描述翻译为中文, 专有名词保留原文
- match_agent.py: strengths/risks/summary 用中文
